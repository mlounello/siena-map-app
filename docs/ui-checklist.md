# UI Checklist (Before Merge)

- [ ] Uses `PageHeader` and `Panel` primitives (no ad-hoc page shell)
- [ ] Uses Siena `Button` variants for all CTA/destructive actions
- [ ] Uses `Badge` for statuses, with consistent tone mapping
- [ ] No new hardcoded hex colors in component/page markup
- [ ] Typography hierarchy follows Siena standards
- [ ] Mobile layout checked at narrow widths
- [ ] Keyboard focus visible on inputs/buttons
- [ ] Empty states and loading states present
- [ ] Error messages rendered in-page and readable
